Group A: Short Questions (2 Marks)

1. Define the term “Protocol” in the context of the Internet.

A protocol is a set of rules and standards that define how data is transmitted and received over the Internet so that different devices can communicate correctly.
Example: HTTP, TCP/IP.

2. What is the primary difference between a Web Browser and a Search Engine?

A Web Browser is software used to access and view websites (e.g., Chrome, Firefox).

A Search Engine is a service used to search information on the web (e.g., Google, Bing).

3. Define the World Wide Web (WWW).

The World Wide Web (WWW) is a system of interlinked web pages and resources accessed over the Internet using web browsers and identified by URLs.

Group B: Long Questions (4 Marks)

5. Explain the client-server architecture of the web with a neat diagram.

The client-server architecture is a model where:

The client (web browser) sends a request.

The server processes the request and sends back a response.

Example: Browser requests a webpage → Web server sends the webpage.

Diagram:

       |
       | Request (HTTP)
       v

       |
       | Response (Web Page)
       v

6. Describe the functions of the following Internet services:
a) Email

Used to send and receive electronic messages.

Supports text, images, and attachments.

Example: Gmail, Outlook.

b) FTP (File Transfer Protocol)

Used to upload and download files between computers.

Commonly used for website file transfer.

c) VoIP (Voice over Internet Protocol)

Allows voice communication over the Internet.

Example: Skype, WhatsApp calls.

7. “The Internet is a network of networks.” Elaborate explaining packet switching.

The Internet connects millions of smaller networks globally, making it a network of networks.

Packet Switching:

Data is broken into small packets.

Each packet travels independently through different paths.

Packets are reassembled at the destination.

Advantages:

Faster transmission

Efficient use of network

Fault tolerant

9. Google domain not working but IP works – Diagnose the problem

Problem:
The issue is with the DNS (Domain Name System).

Explanation:

DNS converts domain names (www.google.com
) into IP addresses.

Since accessing the site via IP works, the server is reachable.

DNS failed to resolve the domain name.

Underlying Technology Failed: DNS service
